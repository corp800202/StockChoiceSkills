# 台股日 K 樣本（威科夫訊號驗證用）

產生日期：2026-11-03。資料截至 2026-10-22。

## 檔案

- `<代號>.csv`：150 檔普通股，欄位 `date,open,high,low,close,volume`。
- `index_TAIEX.csv`：發行量加權股價指數；`index_TPEX.csv`：櫃買指數。
- `manifest.csv`：`code,name,market,industry,group,avg_value,start_date,end_date,rows`。

## 單位與注意事項

- 個股 `volume` 單位為**張**（1 張 = 1000 股），價格為**未還原**的原始價（沒有 `adj_close`），除權息缺口仍在。
- 指數 `volume` 是**成交金額（新台幣元）**，不是張數。來源：證交所 MI_5MINS_HIST / FMTQIK、櫃買中心 Inx_result / st41。
- `avg_value` = 平均每日 收盤價 × 成交量 × 1000（新台幣元），以清理後的資料計算。
- 已刪除成交量為 0 的列與重複日期。
- 原始資料是「目前仍在交易」的股票清單，幾乎沒有已下市股票，有存活者偏差。
- 個股多數從 2019-09 開始（每檔最多 1725 筆）；指數從 2019-01-02 開始。4558 有 2015 年起的資料，指數未涵蓋這段。

## 抽樣方式

- 母體：4 碼普通股 1645 檔（排除 4 檔 TDR 與 3 檔缺成交量的原始檔）。
- `large`：平均成交值前 50 名。
- 其餘依平均成交值中位數分兩半：`mid`（較高的一半）、`small`（較低的一半），各以 `DataFrame.sample(n=50, random_state=42)` 抽 50 檔。
- 名稱、市場、產業取自證交所 ISIN 公開清單（2026-11-03），查不到的用 2021 年本機清單補。
